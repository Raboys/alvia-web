## Reproducción y revisión

Desde la raíz institucional:

```sh
python3 -m http.server 8945 --bind 127.0.0.1
node docs/features/recetas/verify.cjs
```

El runner acepta `ALVIA_V5_URL`, `ALVIA_V5_EVIDENCE` y `ALVIA_PLAYWRIGHT`. Chromium headless, DPR 1; 1440, 1024, 768, 390 y 320 × 900 CSS px. Captura ambas superficies, preparación y estados sin JS; verifica texto ampliado a 200 % con un nombre largo en 720 y 320 px. El ancho 720 comprueba reflujo equivalente a 200 % de zoom desde 1440.
