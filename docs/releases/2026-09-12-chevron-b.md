## Alcance

30 chevrones SVG decorativos de 15 px, incluidos los accesos del header/footer y el botón Copiar de AI Notes. Se retira también una diagonal decorativa junto a «Desde la app de la cobertura». Se conservan textos, destinos y la flecha horizontal de las tarjetas C. Los links mantienen subrayado, los controles conservan foco por teclado y el movimiento se anula cuando el usuario pide movimiento reducido.

El primer mock partía de la portada base. El preflight encontró funcionalidades y mocks ya publicados (`0cd831d`) y, durante el trabajo, el nuevo header mobile (`6176676`). El release integra esas versiones y su documentación: **16 de los 21 archivos del release anterior son idénticos**. Sólo cambian los cuatro HTML y `styles.css`. Las ramas de funcionalidades y header ya publicados se integran como antecedentes del PR para que `main` conserve toda la versión servida, junto con la retirada de landings antiguas.

Los [cuatro mocks originales](../../previews/cta-variants/README.md) quedan versionados como referencia de la elección. No forman parte del paquete público.

## Rollback

Release anterior conservado: `/var/www/alvia.ar/releases/v5-6176676`, que ya incluye el header mobile y las tres funcionalidades. Para revertir sólo esta publicación, comprobar primero que V5 siga apuntando a `v5-8276775`; si cambió, revisar la nueva versión antes de actuar.

```sh
test "$(readlink -f /var/www/alvia.ar/www/v5)" = /var/www/alvia.ar/releases/v5-8276775
sudo ln -s /var/www/alvia.ar/releases/v5-6176676 /var/www/alvia.ar/www/v5-chevron-rollback.next
sudo mv -Tf /var/www/alvia.ar/www/v5-chevron-rollback.next /var/www/alvia.ar/www/v5
```

Después, verificar manifiesto, las cuatro páginas y ambas portadas. No hace falta recargar Nginx; no se modifica su configuración ni se restaura el directorio público completo.
