## Decisiones y por que
- No se limpio el checkout principal en bloque: tenia 36 cambios locales, incluidos planes, wireframes y el concept map no presentes en `main`; se evitaron perdidas de trabajo unico.
- Se retiro el worktree KYC solo despues de commitear su archivo sin rastrear, para preservar `PLAN_KYC_ONBOARDING.md` byte por byte.
- Se borraron solo ramas comprobadas como integradas, equivalentes por parche/arbol o auxiliares; se retuvieron inicialmente las lineas con PR abierto o trabajo unico.
- Se descarto el PR #97 porque su ajuste de Browsershot para Ubuntu estaba sin integrar y probablemente parcialmente obsoleto.
- Se mantuvo el PR #89 por precaucion: su UI de comparacion/scrubber era accesoria y vieja frente a `scribe-harness`, pero el usuario pidio no eliminarlo.
- Se integro `924b2fa`, no la rama completa del #163: la rama habia acumulado siete commits locales de `web-v2` ajenos. El commit codifica en el repo el estado productivo de una sola obra social y evita que una DB nueva vuelva a crear las 14 OOSS ficticias.
- Se genero una clave nueva de 32 bytes Base64 para `AI_NOTES_DELIVERY_KEY` tras comprobar que no habia entregas cifradas pendientes ni una clave valida activa. El deploy exige esa clave para no procesar transcripciones medicas sin cifrado.
