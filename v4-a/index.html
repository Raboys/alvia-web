¿Alvia respeta las reglas de cada cobertura?

Cada cobertura mantiene sus propias reglas.

Alvia verifica el padrón si se requiere, pide autorización y/o identidad según cobertura y muestra copago sólo si corresponde.

Punto de partida Disponibilidad publicada

El padrón se valida sólo cuando la cobertura lo exige. Si esa validación obligatoria da como resultado “no elegible”, “indeterminado” o “no disponible”, el afiliado no puede ingresar. Según la cobertura, se pide autorización y/o identidad, o ninguna de las dos.

Turno

Primero se reserva; después se ingresa.

El copago puede cobrarse al reservar. La autorización y/o identidad, cuando se requieren, se validan al ingresar.
